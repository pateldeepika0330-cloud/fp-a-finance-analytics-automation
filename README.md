#  FP&A Agentic AI Finance Controller

## Overview
This project automates financial planning & analysis (FP&A) using AI agents.

## 🔧 Features
- Data ingestion & cleaning
- Revenue forecasting (rolling average)
- Variance analysis (Actual vs Budget)
- Scenario planning (Best/Worst case)
- Cost center performance analysis
- AI-generated financial insights

## Dashboard
Built using Streamlit for interactive analytics.

## Tech Stack
- Python
- Pandas
- Streamlit
- Matplotlib
